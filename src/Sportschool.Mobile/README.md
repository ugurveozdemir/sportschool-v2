# Sportschool Mobile

Expo + React Native mobile client for athlete and parent read-only flows.

## Local Start

```bash
npm install
EXPO_PUBLIC_API_BASE_URL=http://localhost:5000 npm start
```

Use `http://10.0.2.2:5000` for Android emulator when the API runs on the host machine.

Supported MVP roles: `Athlete`, `Parent`.
